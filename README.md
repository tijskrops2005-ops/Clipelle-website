# Clipelle

Turns one product photo and a short description into a finished 9:16 video ad with an AI presenter and captions, or translates a video you own into other languages. Every step runs on existing services behind one form and one button.
See `CLAUDE.md` for working agreements and `docs/master-prompt.md` for the full brief.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000. The app currently runs in **Demo mode** on mock data (`src/lib/mock/`).
